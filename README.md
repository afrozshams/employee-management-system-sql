# Employee Management System (SQL Project)

## Overview
This project focuses on designing and analyzing an **Employee Management System** using SQL.
It demonstrates how a structured relational database can be used to efficiently manage employee-related data and generate meaningful business insights.

The system integrates multiple aspects such as employee details, job roles, departments, salaries, qualifications, leaves, and payroll into a unified database structure.

## Objectives
- Design a **structured relational database** for managing employee data  
- Ensure **data integrity** using primary keys and foreign key constraints  
- Perform **data analysis using SQL queries**  
- Generate **actionable business insights** for decision-making  

## Database Structure
The database consists of the following tables:
- **Employee** – Stores employee personal details  
- **JobDepartment** – Contains job roles and department information  
- **SalaryBonus** – Stores salary, annual pay, and bonus details  
- **Qualification** – Maintains employee qualifications  
- **Leaves** – Tracks employee leave records  
- **Payroll** – Integrates salary, leaves, and final payment data  

## Key Features
- Relational database design with proper table relationships  
- Data loading using bulk import techniques  
- Data cleaning and preprocessing  
- Complex SQL queries for analysis  
- Use of advanced SQL concepts:
  - **CTE (Common Table Expressions)**  
  - **Window Functions (RANK, DENSE_RANK)**  
  - **Subqueries**

## Analysis Performed
- Employee distribution across departments  
- Salary analysis (average, highest, total expenditure)  
- Top-performing and highest-paid employees  
- Leave and absence patterns  
- Payroll and bonus analysis  
- Department-wise performance insights  

## Key Insights
- Departments like **Finance and IT** have higher employee count and salary allocation  
- Leadership roles offer the **highest compensation**  
- Leave patterns are **consistent across employees**  
- Payroll analysis shows **structured salary distribution and deductions**
